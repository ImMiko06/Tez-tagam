# Current Product Status

Tez Tagam has a customer website, a restaurant board, and a courier account flow. The Node.js/Express server validates orders and stores customers, restaurants, dishes, orders, items, couriers, and status history in PostgreSQL. Customers can register and view their ID and order history; couriers can claim ready orders and update delivery status.

The catalogue includes twelve example restaurants in Almaty and 58 menu items. Menu data is a project seed and does not update automatically from restaurant listings.

The project is prepared for Vercel deployment with a hosted PostgreSQL connection, but has not yet been published. The restaurant board is still a demonstration without staff sign-in; payments, live dispatch, and restaurant integrations are not connected.
